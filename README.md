# MARKET SNIPER — Arizona RP Analytics (Web/React)

Веб-приложение для аналитики рынка и арбитража цен между лавками на серверах Arizona RP (Central Market / ЦР).

## Возможности
- **Поиск выгодных сделок:** находит минимальные цены продажи (`sell`) и максимальные цены скупки (`buy`) для каждого товара.
- **Расчёт чистой прибыли и ROI:** автоматический вычет комиссии лавки/сервера и фильтрация по минимальной рентабельности (`ROI, %`).
- **Импорт CSV:** поддержка загрузки файлов CSV или вставки сырых строк с поддержкой русских и английских названий колонок (`item`/`товар`, `price`/`цена`, `side`/`тип`, `stall`/`лавка`, `server`/`сервер`, `updated`/`время`).
- **Парсинг игровых форматов цен:** распознаёт сокращения `к` / `k` (тысячи) и `кк` / `kk` (миллионы), пробелы и запятые.
- **Фильтрация по серверу:** по умолчанию `Mobile 3` с возможностью переключения на любой сервер проекта.
- **Подтверждение действий:** возможность отмечать проверенные лавки в игре.

## Запуск в разработке
```bash
npm install
npm run dev
```

Приложение запускается на порту `3000`.
